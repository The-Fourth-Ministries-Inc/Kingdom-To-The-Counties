## Full description

Ambassador Companion is a helper app for people who serve with The Fourth Ministries on Kingdom to the Counties. It is for the team, not for the public. You need a Day PIN from a team leader to open the live tools. On event days you can check in, see what is happening now, follow the setup checklist, count guests, sign radios in and out, pack trailers from a shared load list, post a need/praise/note, save a name or short note when you meet someone, look up churches the team is inviting, and read the playbook and counselor notes. Leaders unlock extra tools with a separate Leader PIN. Some notes stay on the phone; shared notes go to systems the ministry uses to run events. The ministry does not sell this information. No ads. Not for children under 13. Help: info@thefourthministries.com.
